# Body — Avatar V0.1: Genesis

**Status:** Owned starter avatar.

## Purpose

Genesis gives the Body a default visual form without tying identity to that appearance.

It is intentionally simple. The goal is not final aesthetics; the goal is to establish a
canonical, owned, fully replaceable VRM 1.0 avatar that can prove the Face pipeline immediately.

## Ownership and customization

Genesis contains no imported third-party avatar asset.

Its geometry, materials, humanoid hierarchy, and first expression are generated by source code in:

```text
src/aicognitive_mind/body/genesis_avatar.py
```

That source is the canonical editable definition. A binary `.vrm` can be emitted with:

```text
python scripts/build_genesis_avatar.py
```

The Body API also generates the same VRM directly at runtime:

```text
GET /v1/body/face/avatar
```

This avoids treating an opaque binary file as the source of truth.

## Avatar V0.1 form

Genesis is a low-poly humanoid starter with:

- VRM 1.0 metadata;
- required humanoid bones;
- head, eyes, hair, torso, arms, hands, legs, and feet;
- editable material definitions;
- a morph-target smile bound to the VRM `happy` expression.

The appearance is deliberately neutral and temporary.

## Face behavior

Opening:

```text
/body/face
```

now loads Genesis automatically.

The existing file chooser remains available. Selecting another owned `.vrm` replaces Genesis in
the browser without modifying Mind identity, memory, or the Face contract.

## Customization rule

Future appearance changes should modify or replace the avatar asset, not change the Mind.

Customization may evolve from source parameters into Blender-authored assets and a dedicated
customization interface, but VRM 1.0 remains the Body's avatar contract.

## V0.1 success criterion

Avatar V0.1 is proven when the Codespace-hosted Face page:

1. opens with Genesis already attached;
2. renders the humanoid without requiring a local avatar file;
3. visibly responds to the existing Neutral and Happy expression controls;
4. still accepts a replacement VRM through the file chooser.
