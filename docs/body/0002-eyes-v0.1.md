# Body — Eyes V0.1

**Status:** First concrete Body faculty.

## Purpose

Eyes V0.1 proves the narrowest useful visual Body path:

```text
local webcam
    ↓
OpenCvVisionSensor
    ↓
transient visual Percept
    ↓
BodyRuntime.see()
    ↓
Mind interpretation later
```

The camera does not identify objects, people, meaning, memory, or beliefs. It captures one visual
frame and reports that a frame exists.

## Memory boundary

A captured frame is JPEG-encoded in memory and returned as a `data:image/jpeg;base64,...`
`Percept.content_ref`.

By default:

- no camera image is written to disk;
- no frame is added to durable memory;
- no identity or belief state is changed;
- no computer-vision interpretation occurs in the Body.

The optional test CLI can save an explicit JPEG copy when a human wants to inspect the capture.
That test copy is not cognitive memory.

## Local Windows setup

Eyes require the optional OpenCV dependency:

```powershell
python -m pip install -e ".[eyes]"
```

Check whether the default webcam can be opened:

```powershell
cognitive-eyes --status-only
```

Capture one transient frame:

```powershell
cognitive-eyes
```

Capture one frame and explicitly save a human-inspection copy:

```powershell
cognitive-eyes --output eyes-v01.jpg
```

If the machine has multiple cameras, try another device index:

```powershell
cognitive-eyes --camera 1 --output eyes-v01.jpg
```

## V0.1 success criterion

Eyes V0.1 is proven on actual hardware when the local command reports:

```text
eyes: available
Eyes V0.1 capture: OK
```

and, when `--output` is requested, the JPEG visibly contains the camera scene.

## Deliberately not included yet

- continuous video;
- face recognition;
- object recognition;
- visual language-model interpretation;
- autonomous observation;
- durable storage of raw frames;
- Mind/Body perception interpretation.

Those belong after one-frame sensory acquisition is proven.
