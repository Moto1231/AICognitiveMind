# Body — Eyes V0.1

**Status:** First concrete Body faculty.

## Deployment rule

The Cognitive Mind application does not require a local Python runtime on the user's Windows
machine. Application code remains in the remote development/runtime environment.

The physical camera is reached through the web browser:

```text
Windows webcam
      ↓
browser getUserMedia()
      ↓ HTTPS
Codespace Body API
      ↓
BrowserVisionIngress
      ↓
transient visual Percept
      ↓
BodyRuntime.see()
      ↓
Mind interpretation later
```

The browser is a hardware bridge, not a second application runtime.

## Memory boundary

A captured frame is JPEG-encoded by the browser and sent to the Body API as a
`data:image/jpeg;base64,...` value.

Eyes V0.1:

- keeps only the latest unconsumed frame in process memory;
- consumes that frame when `BodyRuntime.see()` is called;
- writes no camera image to disk;
- writes nothing to durable cognitive memory;
- changes no identity or belief state;
- performs no computer-vision interpretation.

## Running in Codespaces

Run the existing API in the Codespace and expose its port through the normal Codespaces HTTPS
forwarding. Then open:

```text
/body/eyes
```

in the forwarded application URL.

The browser page provides three actions:

1. **Start camera** — the browser asks Windows for camera permission.
2. **Capture one frame** — one JPEG is sent over HTTPS to the remote Body.
3. **Stop camera** — releases the local camera device.

No Python, OpenCV, or application installation is required on Windows.

## V0.1 success criterion

Eyes V0.1 is proven on actual hardware when the browser page reports:

```text
BODY CAN SEE
```

after one frame has travelled through the browser ingress and been consumed through
`BodyRuntime.see()`.

## Deliberately not included yet

- continuous video;
- face recognition;
- object recognition;
- visual language-model interpretation;
- autonomous observation;
- durable storage of raw frames;
- Mind interpretation of the visual percept.

Those belong after the remote one-frame sensory path is proven.
